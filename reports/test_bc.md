# Testes B e C: score de desempenho

## Métrica: `score`

**B**: 680 jogadores com ≥5 partidas em cada fila. Score médio solo - flex = -0.145 (Wilcoxon p=0.028).

**C** (partidas de solo): Master+ só na flex n=480, mediana 4.99; Master+ na solo n=5316, mediana 5.06. Mann-Whitney (H1: flex_only menor) p=0.21.
Controlando pelo elo solo (OLS): efeito flex_only = +0.071 (p=0.035). Se continua negativo, o jogador rende menos até do que o elo solo dele sugere.

## Métrica: `score_lane`

**B**: 680 jogadores com ≥5 partidas em cada fila. Score médio solo - flex = -0.242 (Wilcoxon p=2.3e-06).

**C** (partidas de solo): Master+ só na flex n=480, mediana 5.02; Master+ na solo n=5316, mediana 5.04. Mann-Whitney (H1: flex_only menor) p=0.43.
Controlando pelo elo solo (OLS): efeito flex_only = +0.053 (p=0.041). Se continua negativo, o jogador rende menos até do que o elo solo dele sugere.
